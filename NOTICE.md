The `factory/` directory and the `/groom`, `/draft`, `/execute`, and
`/address-comments` skills are a portable vendor of IG's ig-spec plugin, kept
here so Cursor and Claude Code can run the same factory without
`/plugin install ig-spec`.

That plugin is UNLICENSED internal software. This clone is for the operator's
own Cursor and Claude Code hosts. It is not a public redistribution of ig-spec.
